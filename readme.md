# Messagerie

## Serveur de messagerie
- Il va hériter de la classe Thread
- Il écouter sur un port en particulier
- Il accepte indéfiniment des connexions
- Il recoit des messages
- Il transfert des messages

## Client de messagerie
- Il va hériter de la classe Thread
- Il se connecte sur un serveur (IP + port)
- Il peut envoyer des messages
- Il peut recevoir des messages
